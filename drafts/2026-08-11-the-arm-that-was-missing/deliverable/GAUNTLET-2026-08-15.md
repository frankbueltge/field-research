# This bundle did not pass its gauntlet. Do not use version 0.1.

**Dated verdict, 2026-08-15, session 120. Written by the practice that built the bundle, on the
exact state the two reviewers were run against (`93855be`).**

The constitution this practice works under (`PROTOCOL.md`, "The gauntlet") lets a work ship **only
if the Verifier passes AND the core objection of the refutation attempt is answered.** Tonight the
first happened and the second did not.

- **Verifier: SOUND WITH QUALIFICATION.** The arithmetic is clean. Every rate, interval, count,
  p-value and cross-file cell in the bundle survived independent recomputation from the primary
  run files — 15,476 CSV↔JSON↔run cells with zero mismatches, all four Fisher p-values reproduced
  against exact rational arithmetic, all hashes correct, no archived run file ever edited, and the
  bundle rebuilding byte for byte. **No fabricated data was found.** Eighteen findings of prose,
  provenance and one metadata field. Full report: `../VERIFIER-120.md`.
- **Interlocutor: the core claim does not survive intact.** Full report, published unedited:
  `../INTERLOCUTOR-12.md`.

**The core objection, which this practice does not dispute.** The bundle's headline property and
the bundle's advertised use are about different things. Reproducibility of an *aggregate rate on a
fixed panel* was offered as the warrant for trusting a *single reading of somebody else's list*.
It is not that warrant — and this arc's own confirmation record says so: of the six transitions it
has ever re-tested, **all four `NOT-RETRIEVABLE` → `RETRIEVABLE` were confirmed and both
`RETRIEVABLE` → `NOT-RETRIEVABLE` were refuted.** The shipped tool performs one pass and no
confirmation. We measured that ourselves, three times, and published neither it nor the fact that
the tool does not produce it.

**Consequence: version 0.1 is withheld, nothing was sent, and no packet exists.** Every correction
below is a new dated event. **No file the reviewers read has been rewritten** — a measurement
record and a reviewed state are not corrected by editing them.

## What the reviewers could not break, recorded because it is evidence too

The bundle rebuilds byte for byte. All published hashes verify. No archived run file has ever been
modified. The overlay is applied in exactly two cells and nowhere else. Every external quotation
and every catalogue count survived first-hand retrieval. The age gradient **survives** the source
split and survives a clustered re-analysis the reviewer ran and this practice had not
(2,744 handles, ICC 0.78 but mean cluster 1.31, design effect 1.24; cluster bootstrap on the
pooled youngest-against-oldest difference, 95 % interval [0.078, 0.178]).
