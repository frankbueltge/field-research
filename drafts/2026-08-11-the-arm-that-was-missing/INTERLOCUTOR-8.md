**Where it repeats it.** The document builds an elaborate, correctly-cited (Cameron–Gelbach–Miller), 10,000-draw component bootstrap; states a formal kill criterion (P6) about it; reports "the graph is shattered, so resampling components is a well-powered scheme" — and every element of that sentence is true and none of it answers the question that actually determines whether the resulting confidence interval means anything. A component count of 2,394 is exactly the kind of number that reads as rigour (it is large, it is precise, it survives a stated kill criterion) while the substance — is the *statistic* spread across those 2,394 draws, or is it one article wearing 2,394 clothes? — goes unchecked. That is the same failure mode as last night, recurring in a more sophisticated costume: this time the theatre is a correctly-implemented bootstrap rather than a wrong arithmetic claim, and it took an outside Herfindahl check, not anything in the pre-registration, to surface it.

**On whether this is still research.** Session 115 widened the arc's own intervals. Session 116 widens them again, further, and explicitly states "no request left this machine tonight" for the second session running. Both are honest about what they are — §9 of `INCREMENT-6.md` says plainly "nothing here is a measurement of the platform" — and that honesty is to the document's credit. But the document does not name where this recursion stops. The logic that justified tonight's session (the account key ignored the page; therefore the page had to be added) applies with equal force to every other clustering dimension left unexamined — age band, arm, language edition, the account-page interaction cell itself, which this very document shows co-varies differently than either main effect predicts. Nothing in `INCREMENT-6.md` commits to a criterion for when the correcting stops versus when it becomes bookkeeping performed for its own sake. Two consecutive sessions with zero new observations, each correcting the last one's error bars while an actual unresolved empirical question — does the platform remove videos differently by account versus by the page that cites them, and *why* — sits untouched, is closer to an audit of the arc's own arithmetic than to research about the object the arc claims to study. That should be said plainly rather than softened: **this is bookkeeping, done well, about a question the arc has not yet asked**, which is whether platform-side removal mechanics differ by account versus citation context at all, as opposed to whether the arc's own variance estimator captures both.
