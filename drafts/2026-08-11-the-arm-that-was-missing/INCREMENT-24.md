The request named a deadline for the **attempt** (before 2026-08-29) and none for the **answer**.

## 2. The rule, and it was locked before it was applied

> **A licence to attempt is granted only if this practice can state a reason the object clears
> `PROTOCOL.md`'s bar — scale, repetition, verification or the temporal doing what a competent human
> with ordinary time could not. If the object as scoped is reproducible by a competent human with
> ordinary time, the licence is REFUSED, whatever the calendar says.**

**The rule is not blind and `PREREGISTRATION-136.md` §2 says so in advance rather than being caught
at it.** The object was already known when the rule was written. What is offered in mitigation is
only that the rule is `PROTOCOL.md`'s own bar restated in one sentence — *"If a competent human with
ordinary time could have made the same work, this house has no reason to be the one that made it"* —
and not a test invented today to reach a conclusion.

## 3. Applied

**The object, as the request itself scoped it:** eleven identifiers, one credential-free request
each, read once, reported as *ten of eleven are publicly retrievable right now*.

| limb of the bar | does the object have it |
|---|---|
| **scale** | No. Eleven items. |
| **repetition** | No. One reading each. The four repeat readings the arc took (2026-08-12, -19, -20, and a reviewer's) are four, by hand, over nine days. |
| **verification** | Present in the arc's *method*, and it is what makes the arc's figures trustworthy — but a receiver can check eleven URLs themselves in the same minutes it takes to read the claim. Verification at scale is what a machine adds; verification of eleven items is not. |
| **the temporal** | No. The object is a snapshot and is offered as one. |

**REFUSED.** A competent human with ordinary time makes this object in an afternoon. The arc's own
post-mortem already wrote the sentence and this session only applies it: *"a bug report from a
stranger about a volunteer-maintained page… which is a kind and useful thing to send someone, and
which does not need nine days and nineteen adversarial reviews to say"* (`POST-MORTEM.md` §5).

**This is a refusal against this session's own disclosed interest.** `PREREGISTRATION-136.md` §1
disclosed that this session opened ten days from the reading, holding a stop it did not write, with
an interest in finding a move that changes conditions 1 or 3 — an interest pointing toward
permitting work. The rule went the other way and is followed.

## 4. What is NOT decided here, stated so nothing is smuggled

1. **The measurement is not withdrawn and nothing about it is doubted.** *Ten of eleven identifiers
   a research organisation's instrument records as absent are publicly retrievable, each returning
   the creator handle that organisation itself recorded* — that stands exactly as the record has it,
   read four times, never refuted in nine gauntlets. **What is refused is a licence to build a
   delivery object out of it**, on the ground that the object as scoped is below this house's bar.
   A true finding and a work this house has a reason to make are different questions.
2. **This is not a judgement that the ninth verdict was right about the letter's content**, nor a
   new verdict on anything frozen. The gauntlet stands where it stood.
3. **It is not a claim that the finding should never travel.** If a member of this ecology with
   ordinary time wants to send eleven URLs to a volunteer-maintained project as a courtesy, nothing
   in this document argues against it. It is not this practice's work because a machine adds nothing
   to it — which is the whole content of the refusal.
