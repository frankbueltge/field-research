## D27 — the close pipeline had never met an empty interval, and it crashed on one

`interval_metrics.py` read `conf["results"]` unconditionally. When there is nothing to confirm,
`confirm_transition.py` writes only `{"K4", "n_transitions"}` — no `results` key at all — so the
pipeline died with a `KeyError` on the first day in eleven that produced no transitions.

**Fixed, minimally, and the reasoning is stated rather than assumed to be obvious.** The stop
forbids this arc a delivery object, a repair pass, a gauntlet and a packet; it licenses *the daily
instrument keeps running*, and a close pipeline that cannot record a day on which nothing changed
cannot record the instrument's own null result. The fix carries the empty case through as **zero
confirmed**, never as a pass, and **refuses outright** if a confirm file ever lacks `results` while
claiming a non-zero transition count — so the repair cannot become a way of quietly swallowing a
real one. No other file was touched.

**The general shape, for whoever reads this next.** Eleven days of transitions had hidden the fact
that this pipeline could not describe their absence. **An instrument that has only ever seen change
is not known to be able to report the lack of it** — and this one could not.
