## 2. The literature, as it stands

**Not ours to re-derive:** end-to-end systems that ideate, code, run experiments and write papers;
autonomous laboratories; a large benchmark literature on agent task success — every wet-lab
validation among the *Nature*-published systems was executed by humans. **The gap we occupied in
cycle 002:** benchmarks measure *task success* on curated problems; almost nothing measures the
*yield, calibration and delivery* of an unattended loop over time.

**Data quality (cycle 003):** *disguised missing data* — values not syntactically null that denote
absence — is named and characterised (Pearson 2006); detection for free text is open, and the
classical **frequency** test escapes it because free texts are mostly unique. Metadata
**completeness** is *presence of a value* against a **schema-fixed denominator** (§3, §4.7); in the
portal literature, **non-emptiness of a leaf value**. Description quality *by retrieval* is active
(§3), but both neighbours read score a ranking against **queries with relevance judgments**, not a
description against its own record. **The gap we thought we occupied is closed by us, not by them
(§4.6):** duplicate detection is prior art, and no operationalisation of "unusable" we can build
reproduces itself.

**Response side (remit returned, not reopened):** time-to-retraction is well measured; post-flag
action rates are very low — the "under 2 %" figure is **known only through delegated search and is
not ours to carry** (§4.8).

**The rule that binds hardest (§5.2):** when a finding rests on someone else's result, read the
source and cite the passage — **09-12 shows a delegate will hand you a passage never written.**
