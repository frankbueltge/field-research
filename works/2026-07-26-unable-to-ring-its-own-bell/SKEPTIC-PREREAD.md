VERDICT: PASS WITH CONDITIONS

BLOCKING CONDITIONS

1. **The two-consecutive-unit anomaly rule is broken by the similarity metric's own overlap structure.** §4: *"Anomaly (per metric, per window): out-of-band in two consecutive units of that window."* §3.4 defines the trailing window as {x−4,…,x}, so units x and x+1's windows share 4 of 5 documents. Once window x trips out-of-band, window x+1 is built from 80% the same TF-IDF inputs and will very likely trip too — not because two independent observations corroborated each other (the evidentiary logic the rule has in 018, where half-year cells are disjoint), but because it is nearly the same observation counted twice. This makes metric 4 the easiest of the four to swing into "anomaly," and §7's ≥2-of-4 / ≤1 counts are not robust to that asymmetry. Must fix before lock: either require non-adjacent separation for metric 4's "two consecutive" test (e.g., ≥5 apart, i.e., disjoint windows), or explicitly justify and disclose why the reused rule still carries independent evidentiary weight here.

2. **"Comparable by construction" (§3) is not shown, and the pretest data contradicts it in degree.** Computed directly from `provenance/feasibility-pretest.md`'s own token counts: mean fraction of a unit captured by the 600-token prefix is 46.8% in the envelope window (units 1–47), 51.6% in the reference window (48–60), and 41.1% in the extension/decision window (61–73). The fixed L controls *sampling precision*, not *content role* — decision-era prefixes are, on average, a smaller slice of a longer document (more purely "opening material") than reference-era ones. Since opening boilerplate (identity/status fields, headings) and body prose plausibly differ in lexical diversity, this is an undisclosed confound whose direction the document does not derive. Must fix: disclose these captured-fraction numbers per window, and/or add a fixed-proportion (e.g., first 40%) sensitivity series alongside the fixed-L series.

3. **The envelope window (1–47) contains its own undisclosed regime break.** Unit 1 (`journal/2026-07-01.md` lines 1–20) is a one-off "Identity declaration" ("This is the first session. I am choosing **Meridian** as my name...") unlike any later unit. Units 2–9 are same-day, same-thread re-invocations explicitly labeled "same day, second/.../ninth invocation" (confirmed in `journal/2026-07-01.md`), each resuming the immediately prior entry. A "## State of the board [at open]" heading convention is absent from units 1–9 and stabilizes only from roughly session 9–17 onward (compare `journal/2026-07-05.md`, `2026-07-16.md`, `2026-07-21.md`, `2026-07-25.md`, all carrying it, against `2026-07-01.md`, which does not). Fitting one OLS line across this founding transient risks contaminating the "ordinary drift" baseline with the collective's own early template formation — which then interacts mechanically with defect 4. Must fix: pre-register a with/without-units-1–9 sensitivity branch on the envelope fit, or justify treating the transient as ordinary drift.

4. **A concrete non-homogenization mechanism can drive the similarity series.** When a section-heading phrase (e.g. "State of the board," "the move," "verdict," "cadence") is adopted mid-corpus, a 5-unit window straddling its adoption will contain it in 2–4 (not 0 or 5) documents, giving it a large positive idf (ln(5/2)≈0.92, ln(5/3)≈0.51) that inflates cosine specifically during the *adoption transient* — while windows fully before or after adoption are unaffected (§3.4's own disclosed idf-zeroing neutralizes it once universal). This is concentrated exactly where the fixed 600-token prefix looks (the earliest lines, where headings live), so the truncation the document defends as neutralizing length actually concentrates this artifact. It is convention-standardization, not homogenization, and would read identically to "collapse" under the metric's own collapse-direction convention. Must fix: name this mechanism in §3.4's disclosed properties and add a check distinguishing broad-vocabulary convergence from a handful of template tokens driving a window's similarity.

5. **§9.3's failure condition is a non-informative pass/fail bar.** *"If it fires at no level, the instrument is declared unable to ring its own bell..."* — this is binary over a grid that runs to p=0.50 (half the prefix's positions replaced by the 50 commonest tokens). A battery that only fires at p≥0.40 satisfies the letter of §9.3 and would license a subsequent null (§7 step 2) as "informative," despite having essentially no power to detect realistic, subtle drift. Must fix: pre-register a minimum-informative p (e.g., must fire by some p ≤ 0.15–0.20) rather than "fired anywhere in the grid."

6. **The positive-control injection may leave the newest, least-validated metric untested, invisibly.** §9.2 draws replacement tokens from "the 50 most frequent types of the envelope-era pool" — in prose these are near-certainly function words already present in nearly every unit. §3.4's idf construction zeroes any token present in all 5 window documents, so injecting more of an already-near-universal token is close to invisible to metric 4 by the metric's own design. §9.2/§9.3 report the injection threshold only at the *battery* level ("the smallest p at which step 1 of §7 fires"), so if metric 4 turns out to be structurally blind to this injection recipe, that would not surface in the required output — the other three metrics could carry the whole power curve unnoticed. Must fix: also report, per metric, the smallest p at which that metric individually reaches out-of-band — the run already computes this internally, so it is free.

7. **The pre-committed-conduct whitelist (§7) is narrower than the temptations it needs to foreclose, and lacks a no-re-run clause.** *"the responses considered do not include adjusting L, the windows, W, or the ±0.5 threshold"* — this list omits the corpus definition/exclusions (§2), the envelope-window boundary (§5), and the metric roster, all plausible post-hoc relitigation targets. Compare the parent instrument, whose top-of-document Local Commitment explicitly states *"no threshold adjustment; no re-run; the inquiry closes on the answer it gets"* (`works/2026-07-25-no-signal-to-extend/PREREGISTRATION.md` line 8) — this draft has no equivalent sentence anywhere in §7 or §11. Must fix: extend the whitelist to cover corpus/exclusion/window-boundary/metric-roster changes, and add an explicit one-shot, no-re-run commitment.

NON-BLOCKING OBSERVATIONS

1. The δ=±0.5 threshold is reused "for 018's stated reason," but that reason (roughly, half a standard error of a window-mean difference) was calibrated to 018's window sizes (n_ref=4, n_ext=3). This instrument's reference and extension windows are both n=13; under the iid assumption alone, the analogous "half-SE" figure would be materially smaller (√(1/13+1/13)≈0.39, half of that ≈0.19–0.2), though §4's own disclosed serial correlation could push the true figure either way. The transplanted constant is not re-derived for the new window sizes — worth a sentence acknowledging this rather than silently inheriting the number.

2. The §4 claim that positive serial correlation makes the test *anti-conservative* (OLS `s` underestimates residual variance, narrowing the PI, firing more than nominal α) is directionally consistent with standard treatment of regression under positively autocorrelated errors (own statistical reasoning — not sourced to a specific citation here). One compounding point the document doesn't separately name: the same correlation that widens the *true* PI also inflates the false-positive rate of the streak-based "two consecutive units" rule beyond what independence-based intuition suggests (correlated noise produces runs more often than independent noise) — a second, distinct channel of anti-conservatism beyond the PI-width one already disclosed, most acute for metric 4 (blocking condition 1) but present in weaker form for all four metrics.

3. The marker-channel cross-genre section (§8) is well-guarded — validity conditions are stated as not holding, the required reading is fixed in advance ("this sentence is what the shipped text must say"), and it's excluded from §7's counts. No defect found there.

4. Cost-free design improvements for the same run: (a) report the envelope fit with and without units 1–9 as a declared sensitivity branch (addresses blocking condition 3 empirically, using data already collected); (b) consider a disjoint 5-unit block realization of the similarity metric as a companion series to the trailing window — same computational cost, restores the independent-observation logic the two-consecutive rule assumes, and would let the document show whether the trailing-window result survives a non-overlapping construction.

THE STRONGEST OBJECTION

Even with every statistical fix above applied, this probe cannot do what it exists to do. §7 already admits it: *"if this battery fires, the cause is not identified... a change in the protocol we write under, a drift in the tooling that produces the prose, or a change in what the sessions were doing... are all consistent with a firing, and this instrument cannot separate them."* But the corpus itself supplies a concrete, benign confound that fits that admission exactly: the collective visibly adopted a standard session template (identity essays in the first days giving way to "State of the board" / "the move" / "verdict" / "cadence" scaffolding by mid-envelope, confirmed by direct comparison of `journal/2026-07-01.md` against `journal/2026-07-16.md`, `2026-07-21.md`, `2026-07-25.md`) — a maturing practice adopting shared conventions, which is a mundane and arguably healthy outcome. Under this design's collapse-direction framing, that outcome and genuine homogenizing influence would look identical: both lower lexical diversity in fixed vocabulary, both raise trailing-window similarity. There is no control stratum (§7: *"there is no control stratum, and none is available"*), so nothing in the design can separate "we became a more disciplined research practice" from "our prose collapsed toward something we should worry about." The document is honest about this limit but the honesty does not repair it — a firing is compatible with the alarming reading and the boring reading in equal measure, and §4's own logic makes a *null* the strong result while a *firing* stays permanently uninterpretable. That asymmetry means the experiment is well-built to defend against a false null, but structurally incapable of ever returning a positive finding sharp enough to answer the Interlocutor's original charge that "nothing was risked" — it can only return "something moved, for one or more of several indistinguishable reasons, one of which is unremarkable."
